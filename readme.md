# Dictionary Files for Urdu and other Languages

Awaz-e-dost shared this file https://www.dropbox.com/s/62kofb6kidzkqej/GoldenDict.zip?dl=1 on his [blog] (https://awaz-e-dost.blogspot.com/2015/03/blog-post_28.html). It has many dictionaries which we have included in this repo too, but the zip file also has portable golden dictionary (version 1.0.1, for reference, incase you do want to download it, not sure if later we got more version. this is for desktop).

## Other lists
I have been using many lists, a few are added [here](https://github.com/ShakesVision/uTools-public/tree/master/replacer-lists) as part of uTools.

A complete Urdu word list without tarakeeb was compiled by Chacha Jaan, Ustaad-e-mohtaram, respected Aijaz Ubaid (Alif Ain) [here](http://muftkutub.blogspot.com/2023/06/blog-post.html) and refers [here](https://drive.google.com/file/d/0B1vEpFWrEBSHVW1taFE1ZjVPclE) as per this [thread](https://www.urduweb.org/mehfil/threads/%D8%A7%D8%B1%D8%AF%D9%88-%D9%BE%D8%B1%D9%88%D9%81-%D8%B1%DB%8C%DA%88%D8%B1-%D8%B3%D9%88%D9%81%D9%B9-%D9%88%DB%8C%D8%A6%D8%B1-%D8%A7%D9%88%D8%B1-%D9%88%D8%B1%DA%88-%D9%BE%D9%84%DA%AF-%D8%A7%D9%86%D8%8C-%D8%A7%D8%B1%D8%AF%D9%88-%DA%A9%D9%85%D9%BE%D9%88%D8%B2%D9%86%DA%AF-%D8%A7%D9%88%D8%B1-%D9%BE%D8%B1%D9%88%D9%81-%D8%B1%DB%8C%DA%88%D9%86%DA%AF-%DA%A9%DB%8C-%D8%A7%DB%8C%DA%A9-%D8%B9%D9%85%D8%AF%DB%81-%DA%A9%D8%A7%D9%88%D8%B4.96237/post-2235467). Its latest versions are always maintained here, so this should be the source if you want to grab the latest file. I have added the file in this repo too though.

A detailed guide of him explaining his proof-reading process is [here](https://www.urduweb.org/mehfil/threads/%D9%85%DB%8C%DA%BA-%DA%A9%D8%B3-%D8%B7%D8%B1%D8%AD-%D9%BE%D8%B1%D9%88%D9%81-%D8%B1%DB%8C%DA%88%D9%86%DA%AF-%DA%A9%D8%B1%D8%AA%D8%A7-%DB%81%D9%88%DA%BA%D8%9F2-0.89438).

[Google Doc](https://docs.google.com/document/d/1EYEWNQ0LMmicDBGwrUnrpxyBbsVYDzbXjbrtPmpITSw/edit?tab=t.0) is shared [here](https://www.urduweb.org/mehfil/threads/%D8%A7%D8%B1%D8%AF%D9%88-%D9%BE%D8%B1%D9%88%D9%81-%D8%B1%DB%8C%DA%88%D8%B1-%D8%B3%D9%88%D9%81%D9%B9-%D9%88%DB%8C%D8%A6%D8%B1-%D8%A7%D9%88%D8%B1-%D9%88%D8%B1%DA%88-%D9%BE%D9%84%DA%AF-%D8%A7%D9%86%D8%8C-%D8%A7%D8%B1%D8%AF%D9%88-%DA%A9%D9%85%D9%BE%D9%88%D8%B2%D9%86%DA%AF-%D8%A7%D9%88%D8%B1-%D9%BE%D8%B1%D9%88%D9%81-%D8%B1%DB%8C%DA%88%D9%86%DA%AF-%DA%A9%DB%8C-%D8%A7%DB%8C%DA%A9-%D8%B9%D9%85%D8%AF%DB%81-%DA%A9%D8%A7%D9%88%D8%B4.96237/post-1906519), if you want to add more pairs to it.
